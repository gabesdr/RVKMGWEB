# Reiknivél fyrir Kílómetrargjald á vefsíðu

## Lýsing

Forritið gerir notendum kleift að út hvað þeir greiða í kílómetragjald (ISK) byggt á þyngdarflokki ökutækisins.
Gjaldatöflur eru byggðar á opinberum upplýsingum frá [island.is/kilometragjald](https://island.is/kilometragjald).

## Eiginleikar

- **Skráning kílómetraaksturs** með upphafs- og lokastöðu
- **Þrír þyngdarflokkar** (A, B, C) með mismunandi gjaldskrá
- **Þyngdarháð gjald** fyrir flokk C (3.501 – 10.000 kg)
- **Söguskráning** sem heldur utan um allar skráningar
- **Heildaryfirlit** yfir ekna kílómetra, fjölda mánaða og meðalgjald á km
- **Sjálfvirk villumeðhöndlun** fyrir ógild inntak (neikvæðar tölur, rangir flokkar, o.fl.)
